# 03_INBOX

Temporary collection area for automatically collected or manually added candidate visual assets.

Workflow:

Source search (e.g. Pixabay API)

↓

03_INBOX

↓

Review and select suitable assets

↓

Move approved assets to:

- 01_MAIN_IMAGE_SCENES (main product image scenes)
- 02_TRY_ON_LIFESTYLE (try-on and lifestyle scenes)

Do not use unreviewed assets from this folder directly for final image generation.
