# AVELEA Background Library

统一背景素材库。所有正式背景图片集中存放在 `BACKGROUNDS/`，不再按主图、试穿、生活方式等用途分类。使用时根据具体 SKU、构图、光线和场景匹配度直接选择。

## 素材收集规则

只收集适合后续把鞋类产品自然融入画面的场景背景。

以下图片直接排除，不进入素材库：

- 冰淇淋、食物、饮料、鲜花、玩具等单一物体的大特写。
- 手持某个物品作为画面主体的近距离照片。
- 人物、物品或食物占据画面大部分面积，几乎没有可用于摆放鞋子的空间。
- 没有清晰地面、桌面、台面、台阶、座椅旁空间或其他可承载产品的场景。
- 纯主体摄影、商品特写、微距摄影，而不是完整环境或生活场景。
- 构图过满、背景杂乱、主体遮挡严重，无法自然加入鞋类产品。
- 明显与鞋类电商视觉无关，无法用于主图、场景图、试穿图或细节图的图片。

优先收集：

- 有完整空间感和景深的室内、户外、街景、家居、酒店、咖啡店、庭院等场景。
- 有地面、桌边、台阶、石台、地毯、座椅旁等可自然摆放鞋子的画面。
- 光线方向明确，主体区域留有足够空间，便于后续重绘融合产品。
- 画面本身有审美，但不会抢过鞋类产品主体。
